📝 如何提交反馈

我们使用 GitHub Issues 收集用户反馈，你需要一个 GitHub 账号才能提交。如果你还没有账号，可以免费注册。

提交反馈前，请尽量包含以下信息，帮助我们更快定位问题：

  • 你使用的鼠标 DPI 和游戏内灵敏度（如果方便）
  • 你在测试中的具体操作（点击了什么按钮、哪一步出了问题）
  • 浏览器类型和版本（如 Edge 131、Chrome 130）
  • 问题截图或录屏（如果有）
