# pubg-sensitivity-tool-demo
本项目是面向PUBG玩家开发的灵敏度辅助调参网页工具，基于前端网页实现。通过画布交互测试采集用户鼠标操作行为，估算常规灵敏度与垂直灵敏度增强参考数值；内置主观追踪、定位急停、缩放模拟瞄准三类模拟测试，为瞄准、开火、多档倍镜参数提供参考依据。  页面收录公开可查证的职业选手与高人气主播灵敏度配置作为对照样本。本工具仅做行为模拟，无法复刻虚幻引擎真实游戏逻辑，输出结果仅作为调参起点，最终参数务必在游戏训练场校验。  产品需求、交互设计、功能规划均由本人独立完成，部分前端代码借助AI编码工具辅助实现，经过阅读调试修改后投入使用。可作为游戏交互体验的实践作品集项目。
